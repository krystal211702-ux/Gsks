# 我的打卡薪資｜簡約質感 PWA

資料夾包含：
- `index.html`：打卡、月曆出勤紀錄、月統計與薪資核對網站
- `manifest.webmanifest`：主畫面安裝設定
- `sw.js`：網站核心檔案離線快取
- `icons/`：192 與 512 像素主畫面圖示

## iPad 安裝提醒
PWA 的 Service Worker 與「加入主畫面」通常需要透過 HTTPS 網址提供服務；從「檔案」直接開啟 ZIP 解壓後的 HTML，可能無法安裝或離線快取。這個 ZIP 已補齊網站所需檔案，但它本身不是公開網址，也不會自動上線。

## 資料保存
出勤資料存在目前瀏覽器的本機儲存空間，不會自動雲端同步。請定期使用網站內的匯出備份。
